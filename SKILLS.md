# Sandpiper Skills Guide

[Sandpiper](https://sandpiper.qut.edu.au/) is a web resource for exploring public shotgun metagenome datasets via taxonomic profiles generated by [SingleM](https://github.com/wwood/singlem). It covers ~100,000+ metagenome runs across thousands of bioprojects.

---

## Finding Samples That Contain a Target Species

### Via the Web Interface

1. Go to **Search** in the top navigation bar.
2. Under **Search by taxonomy**, type your taxon name (species, genus, family, etc.) into the autocomplete field. Suggestions appear as you type.
3. Select a result from the dropdown and press **Search** (or press Enter).
4. The **Search Results** page shows:
   - A summary panel: total matching samples, percentage that are host-associated, geographic spread.
   - An interactive map with clickable sample locations.
   - A paginated, sortable table of matching runs showing:
     - Run accession (links to the full sample view)
     - Environment/organism classification
     - Release year
     - Relative abundance (%) and coverage of the target taxon in that sample

5. Use the **GTDB / GlobDB toggle** to switch between taxonomy databases. The interface will indicate if the taxon is available in one or both.

6. Sort the table by **relative abundance** or **coverage** to rank the most relevant samples.

### Downloading the Results

On the Search Results page, two download buttons are available:

| Button | Content |
|--------|---------|
| **Download CSV (minimal)** | Run accession, relative abundance, taxonomy lineage |
| **Download CSV (with extras)** | Adds latitude, longitude, and additional metadata columns |

These are direct links to:
```
https://sandpiper.qut.edu.au/api/taxonomy_search_csv_minimal/<taxon>?taxonomy_type=gtdb
https://sandpiper.qut.edu.au/api/taxonomy_search_csv/<taxon>?taxonomy_type=gtdb
```

Replace `<taxon>` with the full taxonomy string (URL-encoded if it contains spaces), and `taxonomy_type` with `gtdb` or `globdb`.

## Exploring a Single Sample

Search by SRA accession (e.g. `ERR5004223`) using the **Search by accession** field, or click any run accession in taxonomy search results.

The sample page shows:
- Study metadata (title, abstract, organism, host association, instrument, Gbp)
- **SingleM Prokaryotic Fraction (SPF)**: estimated percentage of reads that are bacterial/archaeal
- **Known species fraction**: percentage of prokaryotic reads assigned to named species
- Interactive **sunburst diagram** of the full community profile — hover to inspect lineages, double-click to zoom into a clade
- Links to the NCBI BioProject and related publications

## Downloading Community Profiles via the API

### Condensed profile for a single run

The condensed format summarises the full 59-marker-gene profile into a single table (one row per taxon):

```
https://sandpiper.qut.edu.au/api/condensed_csv/ERR5004223?taxonomy_type=gtdb
```

Output columns: `sample_name`, `coverage`, `taxonomy`

- `coverage` is the SingleM coverage estimate (reads per base of marker gene)
- `taxonomy` is the full GTDB lineage string (e.g. `Root; d__Bacteria; p__Proteobacteria; ...`)

To use GlobDB instead:
```
https://sandpiper.qut.edu.au/api/condensed_csv/ERR5004223?taxonomy_type=globdb
```

### Condensed profile with extras

Includes additional columns (filled/unfilled flag, relative abundance):

```
https://sandpiper.qut.edu.au/api/condensed_csv_with_extras/ERR5004223?taxonomy_type=gtdb
```

### JSON tree (for programmatic use / visualisation)

The raw hierarchical data used to render the sunburst chart:

```
https://sandpiper.qut.edu.au/api/condensed/ERR5004223?taxonomy_type=gtdb
```

Returns a nested JSON tree of nodes with `name`, `size` (coverage), `condensed_depth`, and `children`.

### Bulk downloads

Full OTU tables for all runs are available from Zenodo (linked from the **About** page). For programmatic access to many samples, the condensed CSV endpoint above can be called per accession, or the Zenodo archives can be downloaded in bulk.

## Other Useful API Endpoints

| Endpoint | Purpose |
|----------|---------|
| `GET /api/sandpiper_stats` | Database statistics (# runs, terabases, bioprojects, version) |
| `GET /api/metadata/<accession>` | Full metadata for a single run |
| `GET /api/taxonomy_search_hints/<partial_taxon>` | Autocomplete suggestions (useful for scripting) |
| `GET /api/taxonomy_search_global_data/<taxon>?taxonomy_type=gtdb` | Summary stats across all samples for a taxon |
| `GET /api/taxonomy_search_run_data/<taxon>?taxonomy_type=gtdb&page=1&page_size=100&sort_field=coverage&sort_direction=desc` | Paginated run-level results for a taxon |
| `GET /api/project?model_bioproject=<PRJNA...>` | All runs in a BioProject |
| `GET /api/random_run?ecological=true&two_gbp=true` | Random ecological run with ≥2 Gbp sequencing |
| `GET /api/accession/<accession>` | Resolve a run/sample/project accession to its type |

All endpoints are under `https://sandpiper.qut.edu.au/api/`.

## Tips

- Taxonomy strings must match exactly what Sandpiper uses internally — use the autocomplete on the Search page or the `taxonomy_search_hints` endpoint to find the correct spelling.
- Both GTDB and GlobDB are supported; specify `?taxonomy_type=gtdb` or `?taxonomy_type=globdb` in API calls (default is GTDB).
- The condensed CSV format is compatible with `singlem summarise` for further analysis or conversion.
- Sample accessions use standard SRA format (e.g. `SRR`, `ERR`, `DRR` prefixes for runs; `SRP`, `ERP`, `DRP` for projects).
